# TFA2 CodeIgniter POS

A CodeIgniter 4 Point-of-Sale application connected to a MySQL database.

## Features

- Home page
- About page
- Customer Accounts page
- User Accounts page
- MySQL database connection
- CodeIgniter Models using Query Builder

## Database Setup

1. Start Apache and MySQL using XAMPP.
2. Open phpMyAdmin.
3. Create a database named `tfa2_pos`.
4. Import the file:

   `database/tfa2_pos.sql`

5. Configure the database settings in the `.env` file.

## Run the Application

Open this URL:

`http://localhost/TFA2/public/`
